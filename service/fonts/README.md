# Arrival banner font

NotoSansCJKsc-Arrival.otf and NotoSansCJKsc-Arrival-Bold.otf are subsets
of Noto Sans CJK SC Regular and Bold,
containing the characters used by `ArrivalOverlay.MESSAGE` in car_overlay.py.
Regenerate this subset when adding characters to the example message.
Source: NotoSansCJK-Regular.ttc and NotoSansCJK-Bold.ttc, SC face (index 2), from the local
fonts-noto-cjk package. The font remains under SIL OFL 1.1; see OFL.txt.
Subsetting was performed with fontTools; it is not a runtime dependency.

Flower introduction subsets: NotoSansCJKsc-Flowers.otf and
NotoSansCJKsc-Flowers-Bold.otf contain the characters in
service/flower_overlay.py INTRODUCTIONS. Generated with fontTools from the
local NotoSansCJK-Regular.ttc/Bold.ttc SC face (index 2), under
/home/huawei/orange-work/nano-offline-work/chroot/usr/share/fonts/opentype/noto/.
The same SIL OFL license in OFL.txt applies. Regenerate when changing copy.

Three-class introductions: NotoSansCJKsc-ThreeFlowers.otf and
NotoSansCJKsc-ThreeFlowers-Bold.otf are subsets for
service/three_flower_overlay.py, from the same local Noto CJK source/SC face
and SIL OFL license. Original arrival and four-class flower subsets are retained.
